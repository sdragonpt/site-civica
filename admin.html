Como publicar equipamentos no site

1
Adicione os equipamentos neste painel usando o botão "Adicionar Equipamento".
2
Exporte o ficheiro machines.json clicando no botão abaixo.
3
Carregue no cPanel ou faça git push — aceda a cPanel → Gestor de Ficheiros → pasta do site e substitua o ficheiro machines.json.
4
Fotos: carregue para images/maquinas/ e use o caminho images/maquinas/nome.jpg no campo Imagem de cada equipamento.

Exportar Dados

Descarregue o ficheiro machines.json para carregar no servidor.

Importar Dados

Restaure dados a partir de um ficheiro machines.json existente.

Zona de Perigo

Estas ações são irreversíveis. Exporte os dados antes de prosseguir.
